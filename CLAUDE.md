# Мир тестового задания

Лендинг-карта с тестовым заданием Кати Колосовой на роль креативного продюсера во ВкусВилле.
Полное ТЗ: `docs/00-general.md` (общее) и `docs/01–04` (разделы). Схема карты: `docs/sketch.png`.

## Как работаем

- Автор не программист. Объяснять просто, без жаргона, по-русски.
- Порядок: карта → разделы по одному. После каждого шага остановиться, показать результат и ждать подтверждения.
- Если задания противоречат друг другу, спросить, а не решать самостоятельно.
- Тексты переносить в `js/content.js` дословно (формулировки, пунктуация, «ёлочки»).

## Запуск

- Сайт на ES-модулях, поэтому двойной клик по `index.html` не работает. Нужен локальный сервер.
- Автор запускает двойным кликом `start.cmd`. Claude запускает конфигурацию `site` из `.claude/launch.json`, порт 8080.
- Сервер — `tools/serve.ps1` (PowerShell). На машине нет Node, Python и git.

## Устройство кода

- `js/main.js` — карта, открытие и закрытие разделов, адреса-якоря, Esc, фокус.
- `js/<раздел>.js` — модуль раздела с функциями `init(root, content)`, `onOpen()`, `onClose()`, `onEscape()`
  и необязательной `beforeOpen(mapButton)` — анимация на карте перед открытием по клику (возвращает Promise).
  `onOpen()` может вернуть элемент — main.js поставит на него фокус вместо заголовка раздела.
  (вернуть `true`, если Esc обработан внутри раздела). Заголовок раздела: `h2` с id `section-title-<раздел>`
  и `tabindex="-1"` (см. `sectionTitleId` в `js/utils.js`).
- `assets/map/*.svg` — заглушки объектов и слоёв фона. Их заменят иллюстрации автора.
- Тёмные оттенки глубины `--c-deep-1..3` в `css/base.css` добавлены сверх палитры с разрешения автора.

## Визуальный стиль

- Главный ориентир — `docs/references/ref-1-park.jpg`: насыщенная природная палитра, без чёрных контуров,
  объём светом (светлое сверху-слева), зернистость и неровные «кистевые» края, много мелких деталей.
  Второй референс — `docs/references/ref-2-giorni.jpg`.
- «Мемное облако» — готовая акварельная картинка автора `docs/references/ref-10-cloud-source-v2.webp`
  (вторая версия, перекрашенная автором), обрезанная и уменьшенная в `assets/map/cloud.png` (920 px).
  Нарисованные кодом варианты отклонены.
  Томаты — форма по `ref-4-tomato.jpg`, однотонные `#ef8d88`, каждый повёрнут по-своему (`--turn`).
  Горы — плоскости как из бумаги по `ref-7-papercut-valley.jpg`: диагональные тени и светлые складки, без штриховки.
  `ref-5-blue-rock.jpg` — штриховка, пока не используется.
- Деревья — плотная крона без видимых веток (вариант с ветками в просветах отклонён).
- Килька высоко выпрыгивает из воды и ныряет обратно головой вниз, томаты выпрыгивают и кувыркаются вместе с ней,
  по воде расходятся круги.
- Айсберг крупнее остальных водных объектов, граница воды — неровная волна.
- Вода синяя, не зелёная.
- В мире нет человечков.
- «Мемное облако» — вытянутый элемент из нескольких слипшихся облаков; это центральная точка лендинга.
- Домик не качается и не парит: стоит на земле, «дышит» (масштаб от основания), тень только у основания.
- Подписи объектов — белый текст без плашки, меньше основного (14/16 px), с мягкой тенью для читаемости.
  Это сознательное решение автора вопреки правилу ТЗ «пастельный фон — тёмный текст».
- Горы редкие и разной высоты, с мягкими вершинами.
- Фон и деревья карты генерирует `tools/generate-world.ps1` (запуск: `powershell -ExecutionPolicy Bypass -File tools\generate-world.ps1`).
  Объекты (`house`, `iceberg`, `fish`, `tomato` в `assets/map/`) нарисованы вручную, облако — картинка автора.
- Цвета неба — переменные `--c-sky-*` в `css/base.css`, цвета травы, воды и деревьев — в генераторе.

## Разделы: статус

- Айсберг (`js/iceberg.js`, `css/iceberg.css`, `assets/iceberg/`) — третий круг правок сделан, ждёт отзыва.
  Решения автора: название «Айсберг вирусного проекта» по центру, НЕ закреплено (уходит при прокрутке);
  белый текст без подложки; подзаголовок с авторскими переносами (на экранах < 600 px — сплошным абзацем);
  активное слово — ровный `#a0c4ff` без теней; карточка вопроса полностью белая; айсберг широкий и короче;
  без водорослей. Граница воды — одна волна-маска (`--wave-*` в css), общая для воды и обеих частей айсберга.
  Esc закрывает весь раздел, даже если открыт вопрос.
- Кнопка «На карту» (общая) — белый текст со стрелкой без плашки, с тенью `--shadow-on-image`.
  Фон разделов по умолчанию — небо, чтобы кнопка читалась.
- Домик (`js/house.js`, `css/house.css`, `assets/house/interior.svg`, дверь `assets/map/door.svg`) —
  собран, ждёт отзыва. Крестик поп-апа закрывает поп-ап и оставляет интерьер (вариант А автора);
  в интерьере кнопка «Открыть проект» открывает поп-ап снова. Первый Esc закрывает поп-ап, второй — раздел.
  Жирное начало пункта (стр. 2): до первой точки, если после неё есть текст; иначе до двоеточия; иначе нет.
  Правки автора: поп-ап НЕ открывается сам — при входе видна комната и кнопка «Открыть проект»; в комнате стоит
  персонаж автора `assets/house/kabachok.png` (исходник `docs/references/ref-9-kabachok-source.webp`) — на ковре,
  ростом до низа картины; поп-ап полупрозрачный белый; полоса прокрутки — белая на прозрачной дорожке;
  в «Как воплотить» убрано «, это пилот».
- Килька, мемы — заглушки.
