# 00. Общий промпт

```
ПРОЕКТ
Сайт-лендинг с решением тестового задания на роль креативного
продюсера во ВкусВилле. Автор: Катя Колосова.
Сайт устроен как маленькая карта мира. На карте четыре объекта,
каждый открывает своё задание. Подробные задания по разделам
лежат в docs/01–04, схема главного экрана в docs/sketch.png.

СТЕК
- Статичный сайт без бэкенда и без сборки: index.html, css/, js/,
  assets/. Чистые HTML, CSS и JavaScript (ES-модули).
- Без фреймворков и тяжёлых библиотек.
- Должен открываться локально и публиковаться на любом статичном
  хостинге (GitHub Pages, Vercel, Netlify).

СТРУКТУРА ФАЙЛОВ
index.html
css/base.css        переменные, типографика, общие компоненты
css/map.css         главная карта
css/<раздел>.css    по файлу на раздел
js/main.js          карта, открытие и закрытие разделов
js/content.js       ВСЕ тексты сайта одним объектом
js/<раздел>.js      логика раздела
assets/map/, assets/iceberg/, assets/house/, assets/kilka/,
assets/memes/

Тексты из docs/ переносить в content.js дословно. Не менять
формулировки, пунктуацию и кавычки-«ёлочки».

ТИПОГРАФИКА
- Заголовки: Unbounded (Google Fonts, с кириллицей).
- Текст: Nunito (Google Fonts, с кириллицей).
- Основной текст не меньше 16 px на мобильном и 18 px на десктопе.

ПАЛИТРА (CSS-переменные)
#ef8d88  #ffadad  #ffd6a5  #fdffb6  #caffbf
#14d1c1  #9bf6ff  #a0c4ff  #bdb2ff  #ffc6ff
Дополнительно: текст #2a2a4a, белый #ffffff.
Ориентир по ролям: небо #9bf6ff и #a0c4ff, суша #caffbf,
вода #14d1c1, глубина #bdb2ff, акценты и томаты #ef8d88,
тёплые детали #ffd6a5 и #fdffb6, облака #ffffff и #ffc6ff.
Весь текст набирать тёмным цветом на светлом фоне или белым на
тёмном. Пастельными цветами текст не набирать.

ВИЗУАЛЬНЫЙ СТИЛЬ
Плоская 2D-иллюстрация с небольшой детализацией. Референсы и
готовые иллюстрации автор пришлёт отдельно. До этого использовать
простые заглушки-фигуры в цветах палитры с подписями.

ГЛАВНАЯ КАРТА (сверху вниз, как на sketch.png)
1. Заголовок: Мир тестового задания
   Подпись: На этой карте спрятано тестовое задание Кати
   Колосовой на роль креативного продюсера во ВкусВилле.
   Нажимайте на всё, что шевелится.
2. Небо. В нём объект «Мемное облако» (два слипшихся облака).
3. Суша с горами на заднем плане. На ней объект «Домик
   спецпроекта».
4. Вода. Слева объект «Айсберг вирусного спеца», справа объект
   «Килька»: рыбка в прыжке, вокруг неё два-три томата.
Под каждым объектом подпись, как указано в кавычках выше
(на сайте без кавычек).

Карта помещается в один экран (100vh) без скролла.
Фон собран из слоёв на всю ширину: небо, горы, суша, вода.
Объекты позиционировать в процентах, чтобы расположение
сохранялось на любой ширине.

КЛИКАБЕЛЬНЫЕ ОБЪЕКТЫ (общее правило)
- Визуально отделены от фона: контур или мягкая тень.
- Постоянно немного двигаются, каждый по-своему и со своим
  периодом: облако дрейфует, домик слегка покачивается, айсберг
  качается на воде, килька и томаты парят вверх-вниз.
- Фон при этом неподвижен.
- При наведении объект увеличивается на 5–8%, курсор pointer.
- Это настоящие кнопки: доступны с клавиатуры, видимый фокус,
  aria-label с названием раздела.

РАЗДЕЛЫ
Объект → раздел → файл с заданием:
- Мемное облако → Мемы → docs/04-memes.md
- Домик спецпроекта → Спецпроект «Качок Кабачок» → docs/02-house.md
- Айсберг вирусного спеца → Вирусный проект → docs/01-iceberg.md
- Килька → Презентация про кильку → docs/03-kilka.md

Раздел открывается поверх карты на той же странице, без
перезагрузки. У каждого раздела свой адрес-якорь (#memes, #house,
#iceberg, #kilka), чтобы кнопка «Назад» в браузере возвращала на
карту, а раздел можно было открыть по прямой ссылке.
Пока раздел открыт, карта под ним не скроллится.

ОБЩИЕ ЭЛЕМЕНТЫ РАЗДЕЛОВ
- Кнопка возврата на карту: одна и та же во всех разделах,
  закреплена, видна при любом скролле.
- Закрытие по Esc.
- После закрытия фокус возвращается на объект карты.

АДАПТИВ
- Мобильный (до 768 px): вертикальная композиция, как на схеме.
- Десктоп: та же композиция, слои растянуты на ширину экрана,
  объекты крупнее, расстояния между ними больше.
- Проверять на ширинах 375, 768, 1280 и 1920 px.

ДОСТУПНОСТЬ И СКОРОСТЬ
- prefers-reduced-motion: отключить постоянное движение объектов
  и анимации переходов, оставить выделение контуром.
- У всех изображений alt.
- Анимации через transform и opacity.
- Изображения разделов грузить лениво.

МЕТА
- title: Мир тестового задания — Катя Колосова для ВкусВилла
- description и Open Graph: текст подписи с главной карты, место
  под картинку превью assets/og.png.
- Фавикон: assets/favicon.png.
- lang="ru".

ПОРЯДОК РАБОТЫ
1. Сначала главная карта с заглушками и пустыми разделами.
2. Затем разделы по одному, каждый по своему файлу из docs/.
3. После каждого шага остановиться и показать результат.
Не переходить к следующему шагу без подтверждения.
Если в заданиях что-то противоречит друг другу, спросить, а не
решать самостоятельно.
```
