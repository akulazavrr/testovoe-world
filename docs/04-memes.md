# 04. Раздел «Мемы»

```
ЗАДАЧА
Сделай раздел «Мемы». Раздел открывается по клику на объект
«Мемное облако» на главной карте. Общие правила сайта (стек,
шрифты, палитра, кнопка возврата) см. docs/00-general.md.

ТОЧКА ВХОДА НА КАРТЕ
В небе один объект: «Мемное облако», два слипшихся облака.
Клик по нему открывает раздел.

ОТКРЫТИЕ
1. Облако распадается на несколько частей, и они разлетаются к
   краям экрана (анимация 500–700 мс).
2. Небо остаётся фоном, карта под ним слегка затемняется.
3. На экране появляются три мема: по очереди, с задержкой
   100–150 мс между ними, лёгкое увеличение и проявление.

СОДЕРЖИМОЕ
- Заголовок раздела: [вставить, например: Мемы, которые меня
  порадовали]
- Три картинки: meme-1, meme-2, meme-3 (файлы лежат в
  assets/memes/).
- Под каждой картинкой место для короткой подписи (необязательное
  поле; если подпись пустая, блок не показывается).
- Картинки не обрезать: сохранять исходные пропорции, вписывать
  в карточку целиком.
- Клик по мему открывает его крупно поверх экрана, повторный клик
  или Esc закрывает крупный вид (первый Esc закрывает мем, второй
  возвращает на карту).

ЗАКРЫТИЕ
Кнопка возврата или Esc: мемы исчезают, части облака слетаются
обратно, пользователь снова на карте.

АДАПТИВ
- Десктоп: три мема в ряд, одинаковая высота карточек.
- Мобильный (до 768 px): мемы столбиком, скролл внутри раздела.

ТЕХНИЧЕСКОЕ
- Пути к картинкам, подписи и alt хранить в js/content.js.
- У каждой картинки alt с кратким описанием.
- Картинки грузить лениво (loading="lazy"), чтобы не тормозили
  карту.
- Учитывать prefers-reduced-motion: облако и мемы появляются и
  исчезают без полёта.

ВИЗУАЛЬНЫЙ СТИЛЬ
См. docs/00-general.md.
```
